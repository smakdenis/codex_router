# Privacy

AI Mode Router is a skills-only plugin. It has no connectors, no MCP servers, no network calls,
and no telemetry.

The router uses only the text and files that the user provides to the current ChatGPT or Codex
conversation. It does not store prompts, attached files, recommendations, feedback, or personal data
outside that conversation. ChatGPT or Codex may process conversation data under the terms and privacy
settings of the host product.

The future API companion described in `API-ROADMAP.md` is not part of this plugin and is not active.
If it is ever built, persistent calibration must be explicitly opt-in and must not store prompt text
or attachments by default.
