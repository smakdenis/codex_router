# Changelog

## 4.0.0

- Add GPT-6 Astra as the highest-capability routing tier.
- Route Astra only when hard end-to-end work or redo risk justifies its higher price.
- Add Astra reasoning-effort and EU Fast-mode compatibility rules.
- Replace the legacy `Light` label with the current `Low` effort label.
- Add Astra routing and regional-compatibility regression cases.

## 3.1.0

- Add declared model fallbacks and two-stage draft/review routing.
- Add GitHub Actions validation on pushes and pull requests.
- Define a confirmation-action contract for the forthcoming optional MCP UI.

## 3.0.1

- Add public marketplace metadata, installation guidance, support and legal links.
- Add a production icon and public-review test scenarios.

## 3.0.0

- Route by expected accepted-result cost, including redo risk.
- Add confidence, qualitative cost tier, and one-question ambiguity handling.
- Add profiles, declarative routing configuration, session-only feedback rules, and safe task decomposition.
- Add public documentation, MIT license, and a manual routing evaluation corpus.
- Document native-plugin limits and a consent-first API roadmap for persistent calibration.
